# Flipper Ethernet Toolkit v0.6 — W5500 / Momentum mntm-012

Экспериментальное приложение для **Flipper Zero** и Ethernet-модуля **W5500 (разъём питания 5 В)**, прошивка **Momentum mntm-012 от 31.12.2025**. Основано непосредственно на версии **v0.5** из репозитория `cox0077/Flipper-Ethernet-Toolkit` (Git blob исходника `2b1cb082ee1732e76e53895d0bb782897736b509`).

## Новое в v0.6

### 13/14 — Network Inventory (улучшено)

Показывает один обнаруженный ARP-сканером узел за раз: **IP, полный MAC и подсказку производителя** (по небольшому встроенному списку OUI). **Вверх/Вниз** переключают узлы. Если список пуст — сначала запустить ARP на экране 5/14.

Подсказка производителя не гарантирует достоверную идентификацию оборудования: локально администрируемые MAC обозначаются как `Local/Random`, остальные отсутствующие в таблице — `Unknown`.

### 14/14 — Network Monitor (новое)

Сравнение **двух последовательных успешных ARP-сканирований**, только в локальном сегменте IPv4:

- `NEW` — новый IP/MAC появился в ответах;
- `NOT_SEEN` — IP, который отвечал раньше, **не ответил в последнем сканировании** (это НЕ доказательство отключения);
- `MAC_CHANGED` — для прежнего IP в новом ответе указан другой MAC-адрес.

**Первый завершившийся ARP-скан** создаёт исходный список (baseline). После **второго скана** появятся счётчики New, Lost, MAC. Третий скан сравнивается со вторым и так далее.

**Управление на экране 14/14:**
- **Короткое OK** — выполнить ARP-скан (можно запускать и на экране 5);
- **Вверх/Вниз** — просмотреть отдельные изменения последнего сравнения;
- **Удерживать OK** — добавить результат в CSV-журнал `/ext/apps_data/flipper_eth_toolkit/changes.csv` (один раз за скан);
- **Влево/Вправо** — переход между экранами;
- **Назад** — выход.

После первого сканирования виден `Baseline saved`; для сравнения запустите второй скан. Домашняя сеть `/24` сканируется примерно 35 секунд при обычных условиях.

**Важные ограничения:**
- Процесс *ручной*, **не** фоновый и не непрерывный: повторный скан делается по кнопке OK.
- Изменения хранятся в оперативной памяти **только до выхода из приложения**; CSV-журнал остаётся на карте памяти.
- При смене подсети или маски предыдущая база сбрасывается, новый скан становится исходным.
- Если список устройств достигает лимита **48 записей**, сравнение не выполняется, чтобы избежать ложных событий из-за переполнения.
- Даже без переполнения ARP-ответы могут теряться из-за фильтрации, сна устройства или перегрузки сети. `NOT_SEEN` означает только отсутствие ответа в последнем скане.
- Журнал CSV создаётся только по **долгому OK**, а не автоматически. Заголовок добавляется при создании файла, новые результаты добавляются в конец. Если изменений нет — записывается `UNCHANGED`; после первого скана — `BASELINE`; при переполнении — `INCOMPLETE`.
- Поля журнала: `scan,event,ip,mac_before,mac_after`. Номер скана сбрасывается после перезапуска приложения, **не является датой или глобальным идентификатором**.

## Сохранены функции v0.5

1. Проверка W5500, Ethernet Link, скорости и автопитания 5 В.
2. MAC, IP, маска, шлюз.
3. DHCPv4 и DNS-сервер (без фонового продления аренды).
4. Ping шлюза.
5. ARP Scanner — только локальная /24, до 254 запросов, максимум 48 найденных устройств.
6. TCP Port Scanner — 10 заданных портов на выбранном шлюзе или ARP-узле.
7. Save Text — `report.txt`, добавляет записи.
8. DNS Lookup — `example.com`, `github.com`, `openai.com`.
9. Wake-on-LAN — устройство из списка ARP.
10. Custom TCP Port — один выбранный порт 1–65535.
11. Export CSV — `report.csv`, перезаписывается.
12. Service Discovery — SSDP и mDNS.
13. Network Inventory — теперь с полным MAC.
14. Network Monitor — сравнение двух сканов и журнал изменений.

Все сетевые проверки выполняйте **только в своей сети или с разрешения её владельца**.

## Файлы на microSD

- `/ext/apps_data/flipper_eth_toolkit/report.txt` — прежний текстовый журнал;
- `/ext/apps_data/flipper_eth_toolkit/report.csv` — предыдущий CSV-экспорт;
- `/ext/apps_data/flipper_eth_toolkit/changes.csv` — **новый** журнал изменений. Обычный экспорт с экрана 11/14 не заменяет `changes.csv`.

Если SD-карта недоступна, появится `SD write failed`. При длительной записи результатов дождитесь завершения операции.

## Обновление без компьютера, только с iPhone

Репозиторий: https://github.com/cox0077/Flipper-Ethernet-Toolkit

1. Скачайте и распакуйте ZIP-архив v0.6 на iPhone в приложении «Файлы».
2. Откройте https://github.com/cox0077/Flipper-Ethernet-Toolkit/upload/main в Safari.
3. Загрузите **три файла из архива** в корень репозитория, заменяя старые: `application.fam`, `flipper_eth_toolkit.c`, `README_RU.md`.
4. Введите сообщение коммита `Update Flipper Ethernet Toolkit v0.6` и сохраните в `main`.
5. Перейдите в GitHub **Actions** и убедитесь, что новая сборка прошла успешно (зелёная галочка). Файл `.github/workflows/build.yml` оставляем без изменений: в нём закреплён SDK Momentum **mntm-012**.
6. Скачайте архив из **Artifacts**, распакуйте и найдите новый `.fap`.
7. Через Flipper Mobile App замените старый `.fap` в `/ext/apps/GPIO/`, затем запустите приложение.
8. Выполните DHCP, ARP (экран 5/14), затем ARP повторно (экран 14/14). Проверьте сравнение и сохранение `changes.csv`.

**Статус проверки:** синтаксис C проверен локально с тестовыми заглушками SDK; алгоритм сравнения проверен отдельными тестами на появление/отсутствие/MAC-изменение, смену подсети и переполнение. **Настоящая сборка SDK Momentum и проверка на реальном Flipper пока не выполнялись.** При ошибке GitHub Actions откройте первый неудачный шаг и передайте текст ошибки для корректировки.
