# Flipper Ethernet Toolkit v0.3 (W5500) — Momentum mntm-012

**Исходный код экспериментальной версии для Flipper Zero с готовым W5500-модулем 5V.**
Новая версия является развитием успешно собранной пользователем v0.2. Компиляция на настоящем Momentum SDK и проверка функций ARP/TCP/SD на физическом Flipper **ещё требуются**.

## Функции

- Автопитание 5V GPIO (по завершении восстановит прежнее состояние).
- Диагностика W5500 по SPI: версия, линк, скорость, дуплекс.
- DHCPv4 (получение IP, маски, шлюза, DNS; пока без продления аренды).
- ICMP Echo (Ping) на IP шлюза.
- **ARP Scanner:** поиск отвечающих устройств в части локальной сети, где находится Flipper. Сканирует адреса в том же /24, что и Flipper, и дополнительно соблюдает полученную маску подсети. Максимум 254 исходящих ARP-запроса, с интервалом 130 мс; сохраняет первые 48 уникальных ответивших устройств с IP и MAC. Не сканирует маршрутизируемые подсети.
- **TCP Port Scanner:** посылает TCP SYN через аппаратные сокеты W5500 выбранному IP. Цель — шлюз по умолчанию или один из ARP-обнаруженных узлов. Проверяет **ровно десять** портов: `21, 22, 23, 53, 80, 139, 443, 445, 3389, 8080`. Результаты: `OPEN`, `CLOSED`, `TIMEOUT`, `ERROR` или `-` (не проверен). Отсутствие ответа не равно подтверждённому закрытому порту.
- **Save Report:** по нажатию ОК добавляет текущие результаты в текстовый отчёт на microSD.

## Экраны и кнопки

Стрелки **Влево / Вправо** — переключение страниц (1–7). **Назад** — выход.

| Экран | Содержание | ОК и другие действия |
|---|---|---|
| 1/7 | W5500 / питание / Ethernet Link | ОК обновить |
| 2/7 | MAC, IP, SN, GW | ОК обновить |
| 3/7 | DHCP, DNS | ОК получить адрес снова |
| 4/7 | ICMP Ping шлюза | ОК проверить шлюз |
| 5/7 | ARP Scanner / найденные IP | ОК запустить; вверх/вниз листать список |
| 6/7 | TCP Port Scanner / цель / результат | **Удерживать ОК**: выбрать шлюз или следующий ARP-узел; **кратко ОК**: сканировать десять портов; вверх/вниз: листать результаты по портам |
| 7/7 | Сохранить отчёт | ОК — добавить снимок результатов на SD |

На экранах 1–4, 7 стрелки вверх/вниз также переключают страницы.

ARP-сканирование обычной домашней /24 занимает приблизительно 35 секунд; TCP-сканирование — до ~12 секунд, если многие порты не отвечают. Во время сканирования можно перелистывать страницы, но одновременно новый скан или сохранение не запускаются.

## Куда сохраняется отчёт

`/ext/apps_data/flipper_eth_toolkit/report.txt`

При каждом успешном нажатии ОК на странице 7 **новый блок добавляется в конец** файла. История прежних блоков не удаляется.

В отчёте есть текущие MAC/IP/маска/шлюз/DNS, количество ARP-запросов, все сохранённые IP и MAC, а также состояние десяти TCP-портов **последней проверенной цели**.

Доступ к текстовому файлу можно получить через файловый менеджер Flipper Mobile App или microSD-карту. Если карта отсутствует или заполнена, будет `Save failed (SD?)`.

## Установка/обновление только с iPhone

Репозиторий: https://github.com/cox0077/Flipper-Ethernet-Toolkit

1. В приложении «Файлы» на iPhone распакуйте ZIP из этого ответа.
2. В браузере перейдите в корень репозитория, **Code** → **Add file** → **Upload files**.
3. Загрузите **три файла**: `application.fam`, `flipper_eth_toolkit.c` и `README_RU.md` из архива. Первые два заменят код v0.2, третий обновит инструкцию внутри репозитория.
4. Commit message: `Update Ethernet Toolkit v0.3`. Сохраните в ветке `main`.
5. Дождитесь новой зелёной галочки GitHub **Actions**. Workflow сборки с фиксированным SDK `mntm-012` остаётся прежним.
6. Actions → новый запуск → **Artifacts** → скачайте ZIP с `.fap` → распакуйте в «Файлы».
7. В **Flipper Mobile App** перезапишите ранее загруженный `.fap` в `/ext/apps/GPIO/`.
8. Подключите W5500 к своей сети. Откройте приложение, проверьте DHCP, затем ARP (экран 5), TCP (экран 6) и сохранение на microSD (экран 7).

При красной сборке откройте ошибку первого упавшего шага компиляции и передайте её для исправления. Не используйте бинарник от другого SDK или другого выпуска Momentum.

## Технические ограничения

- Диагностика **только собственной сети или сети с разрешением на проверку**.
- Только IPv4; максимум 48 сохранённых ARP-ответов; никаких произвольных диапазонов IP/портов.
- ARP-проверка — наличие ответа на широковещательный запрос, а не гарантия, что все устройства найдены.
- TCP-скан — последовательное подключение к десяти портам, без определения службы и без попыток аутентификации.
- Нет DHCP renew/lease expiry, мониторинга, фонового сканирования, DNS Lookup и сохранения результатов каждой TCP-цели отдельно: в отчёт попадают результаты **последнего** TCP-сканирования.
- Работа на оборудовании зависит от прошивки и топологии сети. Сборку и проверки на реальном устройстве нужно подтвердить.
