# Flipper Ethernet Toolkit v0.1

Диагностика W5500 (SPI) для Flipper Zero. Проект исходного кода для сборки `.fap`.

**Возможности:** чтение VERSIONR (ожидается `0x04`), PHYCFGR (link/speed/duplex),
сетевых регистров SHAR/SIPR/SUBR/GAR. Приложение НЕ конфигурирует MAC/IP,
НЕ запрашивает адрес по DHCP, НЕ выполняет ping или сканирование.
Поэтому нулевые IP/MAC после подачи питания — ожидаемое поведение.

## Подключение (Flipper GPIO, именно 3.3 В)

| W5500 | Flipper Zero |
|---|---|
| MO / MOSI | PA7, pin 2 |
| MI / MISO | PA6, pin 3 |
| SCK | PB3, pin 5 |
| nSS / CS | PA4, pin 4 |
| RST | PC3, pin 7 |
| VCC | 3V3, pin 9 |
| GND | GND, pin 8 или 11 |

Питание отключить до монтажа. **Не подавать 5 В** на вход питания W5500,
если конкретная плата не рассчитана на это; GPIO Flipper рассчитаны на 3.3 В.
Проверьте маркировку именно своей платы. Встроенный PHY должен быть соединён
патч-кордом с активным Ethernet-портом коммутатора/роутера.

## Сборка на macOS

1. Установите Python 3 и uFBT (например, через `python3 -m pip install --upgrade ufbt`).
2. Откройте терминал в каталоге с `application.fam`.
3. Запустите `ufbt build`.
4. Подключите Flipper Zero с microSD по USB: `ufbt launch` — собрать, скопировать и запустить.
5. Альтернатива: `ufbt install` — установить на microSD без запуска (если поддерживается вашей версией uFBT).

Если SDK ещё не скачан, первый запуск uFBT потребует доступ в интернет.
Для Momentum/Unleashed используйте соответствующую среду сборки/SDK;
совместимость с альтернативной прошивкой в этой версии не проверена.

## Управление

- Вправо/вниз: следующая страница
- Влево/вверх: предыдущая страница
- OK: перечитать регистры W5500
- Back: выход
- Обновление статуса: примерно каждые 1.5 секунды без нажатий

Страницы: физический линк / сетевые регистры / схема подключения.

## Примечания

- Это исходники, не готовый скомпилированный `.fap`.
- `VERSIONR` W5500 должен вернуть `0x04`.
- Если чип не обнаружен, проверьте питание, общий GND, MOSI/MISO/SCK/CS,
  RESET (PC3) и правильность установки модуля.
- Работа не проверена на физическом Flipper Zero в среде формирования архива.
- SPI-диагностика не сканирует локальную сеть и не меняет настройки роутера.
