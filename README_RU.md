# Flipper Ethernet Toolkit v0.4 — W5500 / Momentum mntm-012

Экспериментальное приложение для Flipper Zero с Ethernet-модулем W5500 и прошивкой **Momentum mntm-012 от 31.12.2025**. Основано на подтверждённо работающей v0.3 из репозитория пользователя.

**Статус v0.4:** синтаксис C проверен локально на компиляторе Clang с заглушками API. Это **не** полноценная сборка под SDK Momentum и **не** аппаратная проверка. Сборка `.fap` должна выполняться GitHub Actions из существующего репозитория, после чего проверяется на Flipper.

## Возможности

Сохранены возможности v0.3:
- Питание 5 В GPIO, SPI, проверка версии W5500, PHY/link.
- DHCPv4 (упрощённый клиент, без обновления аренды) и ICMP Ping шлюза.
- ARP-сканирование **только локального /24** с соблюдением маски подсети, до 254 запросов и 48 найденных устройств.
- TCP-проверка десяти портов выбранного устройства: 21, 22, 23, 53, 80, 139, 443, 445, 3389, 8080.
- Запись текстового журнала на microSD (`report.txt`), с добавлением записей.

Добавлено в v0.4:
- **DNS Lookup**: запрос IPv4 A-записи на DHCP-полученный DNS-сервер. Выбор одного из трёх доменов `example.com`, `github.com`, `openai.com` стрелками вверх/вниз. В этой версии произвольный ввод домена пока не реализован, как и CNAME/AAAA-вывод.
- **Wake-on-LAN**: отправка UDP magic packet на широковещательный адрес, порт 9, для MAC-адреса обнаруженного ранее ARP-сканером устройства. MAC сохраняется **только пока приложение запущено**, поэтому для пробуждения спящего устройства его нужно предварительно обнаружить и не закрывать приложение. Сам факт отправки пакета не гарантирует пробуждение компьютера — WoL должен быть настроен в BIOS/UEFI и ОС.
- **Custom TCP Port**: проверка одного произвольно выбранного TCP-порта **1–65535** на шлюзе или ранее найденном ARP-узле. Результат показывает `OPEN`, `CLOSED`, `TIMEOUT`, `ERROR` или `-` (не проверено). Несколько портов по диапазону не сканируются; это выбор конкретного порта.
- **CSV Export**: файл `report.csv` с сетевыми параметрами, ARP-узлами, результатами TCP (последний стандартный и отдельный custom) и текущим результатом DNS. CSV **перезаписывается** при каждом экспорте, в отличие от `report.txt`.

Ограничения W5500: IPv4, 8 аппаратных сокетов; здесь используются сокеты 0 DHCP/ARP, 1 ICMP, 2 TCP, 3 DNS, 4 WoL. Используйте сканеры исключительно в собственной сети либо с разрешения владельца.

## Экраны и управление

**Короткие Влево / Вправо** — переключение экранов; **Назад** — выход.

| Экран | Назначение | Управление |
|---|---|---|
| 1/11 | W5500 Status | OK — обновить |
| 2/11 | MAC/IP/Mask/Gateway | OK — обновить |
| 3/11 | DHCP / DNS server | OK — новый DHCP-запрос |
| 4/11 | Ping шлюза | OK — выполнить Ping |
| 5/11 | ARP Scanner | OK — поиск; Вверх/Вниз — найденные IP |
| 6/11 | TCP Standard | OK — 10 портов; **долгое OK** — следующая цель; Вверх/Вниз — порты |
| 7/11 | Save Text | OK — добавить запись в `report.txt` |
| 8/11 | DNS Lookup | Вверх/Вниз — выбрать домен; OK — запросить A-запись |
| 9/11 | Wake-on-LAN | **Долгое OK** — следующий ARP-узел; короткое OK — послать magic packet |
| 10/11 | Custom TCP Port | Вверх/Вниз — изменить порт; **долгое Влево/Вправо** — выбрать шаг (1, 10, 100, 1000, 10000); **долгое Вверх/Вниз** — изменить на 10 шагов; **долгое OK** — сменить цель; короткое OK — проверить |
| 11/11 | Export CSV | OK — записать `report.csv` |

Во время текущей сетевой операции новые сетевые операции не запускаются. Проверки выполняются с малой частотой, без перебора паролей, аутентификации или эксплуатации сервисов.

## Файлы на microSD

- `/ext/apps_data/flipper_eth_toolkit/report.txt` — текстовый журнал, в режиме добавления.
- `/ext/apps_data/flipper_eth_toolkit/report.csv` — текущий CSV-снимок, предыдущий перезаписывается.

В CSV стандартный TCP и custom TCP записываются с IP соответствующей последней проверки. Если результат ещё не получен, выводится `-`. Экспорт выполняется после завершения сканирования.

## Обновление с iPhone через GitHub

Репозиторий: https://github.com/cox0077/Flipper-Ethernet-Toolkit

1. Распакуйте ZIP из ответа в iOS «Файлы».
2. Откройте репозиторий GitHub в Safari → `Code` → `Add file` → `Upload files`.
3. Загрузите только **три файла из корня архива**: `application.fam`, `flipper_eth_toolkit.c`, `README_RU.md` (заменят текущие v0.3).
4. Commit message: `Update Flipper Ethernet Toolkit v0.4`. Сохраните в `main`.
5. Откройте `Actions`. Старый `.github/workflows/build.yml` оставьте — он уже привязан к **SDK Momentum mntm-012**.
6. Если сборка успешна, в самом новом запуске скачайте `Artifacts` → ZIP, распакуйте `.fap`.
7. Через Flipper Mobile App загрузите `.fap` в `/ext/apps/GPIO/` взамен старой версии. Если приложение не позволяет передать файл, воспользуйтесь совместимым с iPhone кардридером microSD.
8. Проверьте работу экрана 1, DHCP, Ping, а затем новых экранов 8–11. Сохранённые `.txt`/`.csv` можно посмотреть через файловый менеджер или microSD.

При ошибке сборки откройте первый проблемный шаг и передайте текст ошибки. Не переключайтесь на другой SDK/версию Momentum.

## Что пока не реализовано

- Произвольный ввод имени DNS, повторные DNS-запросы и CNAME-цепочки.
- Память Wake-on-LAN MAC после закрытия приложения, ручной ввод MAC.
- Сканирование произвольных IP за пределами ARP-списка или шлюза.
- Актуализация DHCP-аренды в фоне, IPv6, TLS/HTTPS, полноценный packet capture.
