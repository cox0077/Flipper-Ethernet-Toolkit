# Flipper Ethernet Toolkit v0.5 — W5500 / Momentum mntm-012

Экспериментальное приложение для **Flipper Zero** с Ethernet-модулем **W5500 (5V)** и прошивкой **Momentum mntm-012 от 31.12.2025**. Исходники разработаны как продолжение рабочей v0.4.

## Новые функции v0.5

### 12/13 — Service Discovery

- **SSDP**: отправка M-SEARCH на стандартную multicast-группу `239.255.255.250:1900`, краткий разбор ответов HTTP 200 и поля `ST:`. Не выполняет аутентификацию и не меняет настройки устройств.
- **mDNS**: запрос списка типов служб (`_services._dns-sd._udp.local`, PTR) на `224.0.0.251:5353`. Запрос отправляется с нестандартного UDP-порта для получения unicast-ответов, там, где устройства поддерживают такой режим.
- Ответы ограничены **12 записями**, показываются IP и краткий тип службы. Ожидание ответов — 3,8 секунды.
- На **12/13**: **Вверх** переключает SSDP ↔ mDNS после завершения запроса, **ОК** отправляет запрос, **Вниз** листает результаты.

Это **активное обнаружение поддерживаемых служб**, а не полный сетевой сканер. Если устройства не поддерживают SSDP/mDNS, на экране останется `Found: 0` — это нормально. Ответы могут блокироваться оборудованием, а mDNS обычно ограничивается локальным сегментом сети.

### 13/13 — Network Inventory

- Просмотр IP обнаруженных ARP-сканером устройств.
- Короткая подсказка по изготовителю MAC через встроенный **неполный** набор известных OUI: Raspberry Pi, Espressif, Apple, Intel, MikroTik.
- Локально администрируемые и случайные MAC помечаются `Local/Random`. Остальные неизвестные — `Unknown`. Подсказка не удостоверяет производителя или тип устройства.
- **Вверх/Вниз** — переключение между ARP-устройствами; список берётся из ранее выполненного ARP-скана на экране 5.

### Отчёты

- В `report.txt` добавлены строки `SERVICE` и подсказки изготовителя рядом с обнаруженными ARP-MAC.
- В `report.csv` расширено поле `details` для строк ARP и добавлены строки `SERVICE` для последнего SSDP/mDNS-запроса. **CSV перезаписывается** при каждом экспорте; `report.txt` добавляется в конец.

Файлы:

- `/ext/apps_data/flipper_eth_toolkit/report.txt`
- `/ext/apps_data/flipper_eth_toolkit/report.csv`

## Сохранённые функции v0.4

1. W5500 / питание 5 В / состояние PHY.
2. MAC, IP, маска, шлюз.
3. DHCPv4 и DNS-сервер.
4. ICMP Ping шлюза.
5. ARP Scanner (локальный /24, до 254 проб, до 48 сохранённых узлов).
6. TCP Scanner (10 портов выбранного устройства).
7. Сохранение текстового отчёта.
8. DNS Lookup (три заданных домена).
9. Wake-on-LAN (ранее обнаруженный ARP MAC).
10. Custom TCP Port (порт 1–65535 на выбранном шлюзе или ARP-узле).
11. Export CSV.
12. Service Discovery (SSDP / mDNS).
13. Network Inventory (IP + MAC Vendor).

**Влево/Вправо** — смена экрана, **Назад** — выход. Управление экранами 1–11 не изменено.

## Установка через iPhone

GitHub: https://github.com/cox0077/Flipper-Ethernet-Toolkit

1. Скачайте и распакуйте этот ZIP через приложение «Файлы».
2. Откройте страницу загрузки файлов ветки `main`: https://github.com/cox0077/Flipper-Ethernet-Toolkit/upload/main
3. Замените файлы из архива в корне репозитория: `application.fam`, `flipper_eth_toolkit.c`, `README_RU.md`.
4. Сообщение коммита: `Update Ethernet Toolkit v0.5`.
5. Откройте GitHub **Actions**, выберите сборку с этим коммитом и убедитесь, что она успешна.
6. Скачайте **Artifacts**, распакуйте архив, загрузите собранный `.fap` на Flipper в `/ext/apps/GPIO/` через Flipper Mobile App или iPhone + кардридер microSD.
7. Проверьте статус W5500 и DHCP. На экране 12 проверьте SSDP, затем mDNS. На экране 5 выполните ARP-скан и посмотрите экран 13. На экране 11 выполните CSV Export.

`build.yml` менять не нужно: в текущем репозитории сборка закреплена за SDK Momentum mntm-012.

## Проверки и ограничения

- **Проверено локально:** синтаксис C компилятором Clang с имитационными заголовками Flipper API, разбор тестовых mDNS/SSDP-ответов, обнаружение повторяющихся записей и классификация MAC.
- **Не проверено:** полноценная сборка на SDK Momentum и работа mDNS/SSDP на реальной сети и устройстве. Это нужно сделать с GitHub Actions и Flipper Zero.
- Запросы mDNS/SSDP отправляются только в локальные multicast-группы, не подразумевают обход маршрутизируемых сетей.
- Если в сервисах текст длиннее 39 символов, он сокращается. Если ответ слишком велик, не помещается в буфер или содержит нестандартные поля, он может быть проигнорирован.
- Только IPv4; нет TLS/HTTPS, DHCP lease renew, полной базы OUI или пассивного захвата Ethernet-трафика.
- Используйте сетевые проверки только в своей сети либо там, где у вас есть разрешение.
